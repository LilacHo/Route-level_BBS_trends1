# Route-level_BBS_trends — base vs. anthro release

Route-level trend models for every BBS species in the project's species
list (all 12 bird groups), using an intrinsic CAR (iCAR) spatial model fit
in Stan via `bbsBayes2` and `cmdstanr`. Every species gets exactly two
models, fit on identical data so they're directly comparable:

```
log(lambda[r,t]) = alpha[r] + beta[r]*t + gamma1 * Anthro[r,t]     (anthro; gamma1 = 0 for base)
```

| model_tag | covariate | Stan model |
|---|---|---|
| `base`   | none | `slope_iCAR_route_NB_New.stan` |
| `anthro` | `data/Anthro.csv` — proportion of the BBS route 1km buffer in developed + cultivated-crop land cover | `slope_iCAR_route_NB_New_covariate.stan` |

`anthro` is applied the same way project-wide, independent of a species'
bird group.

The generation of `Anthro.csv` and NLCD class codes are from the companion
[BBS_landcover](https://github.com/LilacHo/BBS_landcover) repo, which
computes route-buffer land-cover proportions from annual NLCD rasters.

Models adapted from Adam Smith's
[Route-level_BBS_trends](https://github.com/AdamCSmithCWS/Route-level_BBS_trends).

## Spatial reference

All latitude/longitude coordinates in this release (BBS route locations,
and the SDM raster extraction in 3c) use the WGS84 geodetic datum
(EPSG:4326).

## Run order

```
0_prepare_aou.R
-> 1c_species_iCAR_covariates.R
-> 2c_generate_route_trend_csvs_covariates.R
-> 3c_add_SDM_covariates.R
-> 4c_statistical_analysis_and_visualization_covariates.R
```

## Inputs you need to supply

Everything else is generated by the scripts below. Only these are not:

- `data/spp_names_codes_group.csv` — list of species and their bird group
  (`aridlands`, `boreal_forests`, `eastern_forests`, `western_forests`,
  `subtropical_forests`, `grasslands`, `marshlands`, `coastal`, `waterbirds`,
  `generalists`, `arctic`, `urban_suburban`). Access through [Bateman et al. 2020]
  (https://adaptwest.databasin.org/pages/audubon-survival-by-degrees/).
- `data/Anthro.csv` — the anthro covariate, one row per BBS route per year
  (`CountryNum/StateNum/Route/.../year/Anthro`), used project-wide regardless
  of species group. Produced by the
  [BBS_landcover](https://github.com/LilacHo/BBS_landcover) repo.
- `data/rcp45_<group>/`, `data/rcp85_<group>/` (one pair per bird group) —
  per-species SDM classified-change rasters (`.tif`), named
  `<group>_<species_code>_breeding_2025_<45|85>_ENSEMBLE_classifiedchange.tif`.
  Access through [Bateman et al. 2020](https://adaptwest.databasin.org/pages/audubon-survival-by-degrees/).
- BBS survey data — `bbsBayes2` fetches and caches this locally the
  first time it's needed; run `bbsBayes2::fetch_bbs_data()` once beforehand
  if it isn't cached yet.

## Scripts

### 0_prepare_aou.R

Adds AOU numeric species codes to the species list and flags which species
are in `bbsBayes2`'s BBS species table.

- Reads: `data/spp_names_codes_group.csv`
- Writes: `data/spp_names_codes_group_aou.csv`

### 1c_species_iCAR_covariates.R

Fits both models above (`base`, `anthro`) for every species in the
project's list, across all 12 groups. For each species: pulls BBS route
data via `bbsBayes2`, joins the anthro covariate by route + year, drops any
route-year missing it (so both models see identical rows), builds a Voronoi
route-adjacency structure, and samples each Stan model. A long run (~600
species x 2 models); safe to stop and resume.

- Reads: `data/spp_names_codes_group_aou.csv`, `data/Anthro.csv`
- Writes per species x model_tag:
  - `output/rds/<species>_iCAR_<tag>_2010_2025_stanfit.rds` — full posterior draws
  - `output/rds/<species>_iCAR_<tag>_2010_2025_summ_fit.rds` — posterior summary
  - `data/route_info/<species>_<tag>_2010_2025_route_info.rds` — route/lat/lon lookup
  - `data/stan_data/<species>_<tag>_2010_2025_stan_data.RData` — the exact data fed to Stan
  - `output/diagnostics_covariates_all_species_anthro_2010_2025.csv` — one row per species x tag (Rhat, ESS, gamma1, fit time)
  - `output/files/gamma_lookup_all_species_anthro_2010_2025.csv` — via `helper/gamma_lookup.R`, gamma1's full posterior summary across every species
- Skips a species/tag whose output already exists unless `force_refit <- TRUE`.
- Uses `functions/neighbours_define_voronoi.R` and `helper/gamma_lookup.R`.

### 2c_generate_route_trend_csvs_covariates.R

Post-processing only — no fitting. Reads every species x model_tag's
`summ_fit.rds` + `route_info.rds` from 1c and converts the raw `alpha`/`beta`
posterior means into interpretable quantities: `trend = 100 * (exp(beta) - 1)`
(annual % change, with a 90% CI) and `rel_abundance = exp(alpha)`. Also
pulls gamma1's mean and 90% CI for the `anthro` model, across every
species/group.

- Reads: `output/rds/*_summ_fit.rds`, `data/route_info/*_route_info.rds`,
  `data/spp_names_codes_group_aou.csv`
- Writes:
  - `output/species_routes_covariates/all_route_trends_2010_2025.csv` — every route x species x model, with a `group` column
  - `output/species_routes_covariates/all_model_level_summary_2010_2025.csv` — one row per species x model (gamma1 + its CI), with a `group` column
  - `output/species_routes_covariates/per_species/<species>_<tag>_route_trends.csv` — same per-route data, split one file per species x tag (needed by 3c)

### 3c_add_SDM_covariates.R

Adds climate-suitability columns to each per-species-per-model file from 2c,
by extracting SDM raster values at each route's location. Each species'
raster folder is resolved from its own bird group, so this runs across all
groups automatically. A species with no matching raster is skipped (with a
warning), not treated as fatal.

- Reads: `output/species_routes_covariates/per_species/*.csv`,
  `data/spp_names_codes_group_aou.csv`, `data/rcp45_<group>/`,
  `data/rcp85_<group>/`
- Writes: `output/species_routes_covariates/per_species_sdm/<species>_<tag>_route_trends_sdm.csv`
  (same columns as the input, plus `rcp45`/`rcp85` — a 0-7 classified-change
  code; see the raster value legend in the script's header comment)

### 4c_statistical_analysis_and_visualization_covariates.R

Statistical comparison and violin plots (with compact-letter-display
annotations from pairwise Wilcoxon tests, BH-adjusted) of route-level
`trend` by SDM classified-change category. Automatically loops over
`model_tag` in `{base, anthro}` x every bird group present in the SDM data
(discovered from the data). A group x model_tag combination with no rows is
skipped with a message; every output filename includes the group and
model_tag so combinations never overwrite each other.

- Reads: `output/species_routes_covariates/per_species_sdm/*.csv` (from 3c),
  `data/spp_names_codes_group_aou.csv`
- Writes: stats tables under `output/species_routes_covariates/per_species_sdm_stats/`
  and plots under `output/species_routes_covariates/per_species_sdm_plot/`,
  one set per group x model_tag combination

## Supporting files

- `functions/neighbours_define_voronoi.R` — builds the Voronoi-polygon
  spatial adjacency structure (node1/node2 edge lists) that the iCAR spatial
  priors on alpha/beta need. Used by 1c.
- `functions/posterior_summary_functions.R` — sourced by 1c; posterior
  summary helpers.
- `helper/gamma_lookup.R` — pulls gamma1's posterior summary (mean, median,
  sd, q5/q95, Rhat, ESS) out of every species x model_tag's `summ_fit.rds`,
  prints a credibility/convergence summary, and writes
  `output/files/gamma_lookup_<bird_group>_<firstYear>_<lastYear>.csv`.
  Sourced and called automatically at the end of 1c; can also be run
  standalone.
- `models/slope_iCAR_route_NB_New.stan` — the no-covariate iCAR route-level
  slope model (`base`).
- `models/slope_iCAR_route_NB_New_covariate.stan` — the same model with one
  added covariate term (`anthro`).
